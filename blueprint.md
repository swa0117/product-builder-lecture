# Lotto Number Generator - Blueprint

## Overview
A modern, interactive, and visually stunning Lotto Number Generator. Users can generate 6 random numbers (1-45) with smooth animations and a premium look and feel, adhering to modern web standards and high-performance design principles.

## Features & Design
- **Interactive Generator:** A central action button with a glow effect that triggers the generation.
- **Visual Feedback:** Lotto balls appearing with a "pop" animation and dynamic colors.
- **Modern Aesthetics:**
    - Gradient backgrounds and subtle noise texture.
    - Soft, multi-layered drop shadows for depth.
    - Responsive design using Container Queries and Flexbox/Grid.
- **History Tracking:** A list showing previously generated sets of numbers.
- **Tech Stack:** Vanilla HTML5, Modern CSS (Baseline), and ES6+ JavaScript.
